# 💬 ChatGPT Impostor

Una interfaz de chat simple e interactiva que simula respuestas de una IA al estilo de ChatGPT.  
Creada con **HTML**, **CSS** y **JavaScript** puro, este proyecto es ideal para practicar conceptos de manipulación del DOM, estilos responsivos y lógica de interacción en tiempo real.

---

## 🚀 Características

- **Interfaz moderna y responsiva** gracias a `flexbox` y media queries.
- **Simulación de escritura** para dar realismo a las respuestas de la IA.
- **Respuestas aleatorias** desde un set predefinido de frases.
- **Envío de mensajes** con clic o presionando **Enter** (Shift+Enter para salto de línea).
- **Autoajuste de altura** del campo de texto según el contenido.

---

## 📂 Estructura del Proyecto

├── index.html # Estructura principal del chat
├── styles.css # Estilos y diseño responsivo
└── script.js # Lógica de interacción y simulación de IA
